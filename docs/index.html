01 / The problem

Public data is available.
Exploration is another problem.

The work

The World Bank publishes population observations through an API. Building an explorable interface requires more than plotting those numbers: the records need to be collected, matched to economy metadata, checked and made available to a web application.

I built a separation between data ingestion and interactive serving. The ingestion process prepares a reusable dataset in S3; the dashboard reads that dataset and lets visitors navigate the globe without sending a new World Bank API request for each selection.

02 / The system

One dataset.
Two independent runtimes.

The ingestion Lambda and dashboard Lambda have different jobs. S3 sits between them as the handoff point, so data collection does not need to run during browser interactions.

03 / Engineering notes

The choices behind
the interface.

These are the details that shaped the project more than the visual styling.

D/01

Prepare once, explore repeatedly.

The dashboard reads the enriched S3 dataset at process startup, rather than querying the World Bank or S3 on every click. Tradeoff: quick in-memory filtering, but updated data needs a fresh process to be loaded.

D/02

Don't confuse missing with zero.

Unreported population values stay null. Aggregate groups are identified separately from individual economies, and the map uses a logarithmic Viridis scale. Why: visual clarity shouldn't erase the underlying meaning of the data.

D/03

Check that extraction is complete.

The ingestion code follows API pagination and compares collected record counts against the totals reported by the API. Limit: completeness checks do not guarantee that every individual observation is correct.

D/04

Keep ingestion and serving separate.

Two Lambda functions, each packaged in a Docker image, handle different workloads. GitHub Actions builds and publishes the images to ECR. Tradeoff: an explicit deployment process, with some release steps still manual.

Data interpretation

The World Bank's term “economy” includes territories as well as sovereign states. The latest reported observation for a selected economy can differ from the year represented on the globe.

04 / Development record

Deployed is a milestone,
not the end of the project.

A practical distinction between what can be used today, what I'm building now and what is still on the list.

01 / Deployed

Population explorer

World Bank ingestion, S3 data publication, interactive globe, country history, a public Lambda-hosted app and container build workflows.

02 / In development

Agentic data exploration

Work is underway on an MCP-enabled workflow for indicator discovery, data retrieval and SQL-based analysis with DuckDB and LLM tooling. This is not part of the public dashboard yet.

03 / Planned

Operational refinement

Automated refresh and cache handling, broader data-quality checks, and a fully automated dashboard image update after a successful build.
