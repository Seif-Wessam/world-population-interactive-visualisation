The experience

From global overview to country-level detail.

The interface makes a large public dataset approachable while keeping the underlying observations and source methodology visible.

Interactive population globe

Rotate the globe and explore more than 200 World Bank economies through colour-coded population estimates. Hover to inspect values and observation years.

Historical population trends

Select an economy to view its most recent reported observation and a historical population chart, with annual data extending back to 1970 where available.

Traceable public data

Observations come from the World Bank Indicators API. The ingestion pipeline checks pagination, preserves missing values, and separates aggregate groups from individual economies.

System architecture

An end-to-end serverless pipeline.

Data ingestion and web serving run as separate container-based Lambda services. The public application reads a prepared dataset rather than querying World Bank on every interaction.

01 / Data ingestion

Extract, enrich, verify, and publish.

01World Bank Indicators APIPopulation observations and economy metadata
02Python ingestion LambdaPagination, record counts, region enrichment
03Amazon S3Enriched JSON dataset for the dashboard

The ingestion job runs separately from deployment; new observations are not fetched by every dashboard visitor.

02 / Interactive delivery

Serve the interface and respond to user selections.

01Browser + Lambda Function URLPublic HTTPS access to the dashboard
02Lambda Web Adapter + GunicornHTTP requests routed to the web application
03Dash / Flask + pandasS3 data loaded into memory at process startup

Country-selection callbacks filter the in-memory data. Plotly handles interactions such as globe rotation in the browser.

Engineering decisions

More than a front-end visualization.

The project combines ingestion safeguards, runtime architecture, automated tests, and cloud deployments.

Careful data handling

API pagination and reported record totals are checked. Missing observations stay null instead of being treated as zero.

Efficient interactions

The dashboard loads prepared S3 data at Python process startup, then filters it in memory for country-selection callbacks.

Versioned cloud builds

GitHub Actions runs Python tests and builds Docker images in ECR. The final dashboard Lambda image update is currently manual.

Project development

Deployed today. Built to evolve.

The current dashboard is a completed, publicly accessible milestone. In parallel, the next stage is actively focused on improving automation and building the agentic framework for more flexible World Bank data exploration.

Implemented & deployed

Population dashboard

World Bank data ingestion, metadata enrichment, S3 publication, an interactive globe and historical charts, and a public Lambda-hosted web application.

Planned improvements

Reliability and automation

Automated dataset refreshes, stronger quality checks, cache freshness handling, and automatic dashboard Lambda updates from new container builds.

In development

Agentic data exploration

Building an MCP-enabled and agentic analytics workflow for indicator discovery, auditable retrieval, and SQL-based analysis. This work is currently in development and is separate from the already deployed dashboard milestone.

Data source and interpretation: Population observations originate from the World Bank's Population, total indicator (SP.POP.TOTL). World Bank “economies” include territories as well as sovereign states. Aggregate entries are excluded from individual-economy views; missing data must not be read as zero. The globe's colours use a logarithmic population scale.
